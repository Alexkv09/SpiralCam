# SpiralCam v6 — editorial сторінка «Ідеї» та футер

Зміни у версії 6:
- Відновлено оригінальний футер v4 на головному екрані: `SHOOT · LEARN · CREATE` / `✳` / `© SPIRALCAM`. Він притиснутий до низу без прокручування головної.
- «Ідеї» переведено у той самий світлий фотографічний editorial-стиль: паперовий фон, виразна serif-типографіка, фото-прев’ю, строгі картки, нумерація п’яти тематичних добірок, світлий перегляд фотографії, спокійні інструкції до датчика.
- Залишено всі 5×5=25 фотоприкладів та їхні налаштовані напрямні. 5 фотографій тварин локальні, 20 інших використовують зовнішні URL та потребують доступу до мережі.
- Не змінено інтерфейс чи логіку камери, галереї, збереження фото та керування датчиками.
- Підвищено версію PWA-кешу до `spiralcam-app-v6`. Публікація: розпакувати файли в корені GitHub Pages без зміни директорій.

# SpiralCam v5 — мінімалістична головна сторінка

У версії v5 спрощено лише головну: назва SpiralCam, слоган «Геометрія краси.», невисоке фото зі спіраллю та дві великі кнопки «Камера» й «Ідеї», розміщені ближче до середини екрана. Прибрано другорядні тексти, підписи на фото й нижній футер. Камера, галерея та ідеї функціонально не змінювались. Оновлено PWA cache до spiralcam-app-v5.

# SpiralCam v4 — камера із золотою спіраллю

Статичний мобільний вебзастосунок **HTML + CSS + JavaScript** без бекенду, реєстрації та API-ключів. Розрахований на GitHub Pages, iPhone та Android. Усе, що учень фотографує, залишається лише у сховищі його браузера.

## Що виправлено в v4

- **Новий головний екран:** фото-редакційний стиль, світла паперова палітра, справжній знімок лисиці, плівкова перфорація, інформація про композицію та дві чіткі кнопки. Камеру/галерею/«Ідеї» не змінено. Усі фотографії на головній завантажуються локально.
- **Вимкнення масштабування інтерфейсу:** viewport із забороною user scaling, CSS `touch-action: pan-x pan-y` і захист від pinch/gesture/dblclick на iOS. Звичайне гортання по вертикалі та горизонталі збережено. Зверніть увагу, що це також обмежує користувачам можливість збільшення тексту жестами; за потреби для доступності налаштування можна прибрати.
- **Оновлення:** кеш PWA піднятий до `spiralcam-app-v4`.

## Що виправлено в v3

- **Назва:** SpiralCam у заголовку, головному екрані, маніфесті та назвах завантажених фото. **Назва внутрішньої бази IndexedDB залишена без змін** (`SpiraCamPhotos`), щоб збережені користувачем знімки попередніх версій не зникли.
- **Прев’ю після галереї:** потік показується через синхронізований Canvas, який завжди заповнює 100% видимої рамки. Для iPhone Safari нативне відео залишається джерелом, але не залежить від відображення нативного `<video>` поверх інших елементів. Кадрування у прев’ю повторює алгоритм знімка.
- **Геометрія вікна:** вміст рамки перераховується за фактичними розмірами області камери, через `ResizeObserver`, `visualViewport` і після закриття галереї.
- **Фотоприклади:** для портрета чоловіка зміщено центр спіралі до обличчя (`x=0.56, y=0.42`); для «Корисна тарілка» — до середини кадру (`0.50, 0.50`); для «Піца зверху» — нижче (`0.62, 0.57`). Обидва види прикладів використовують однакове співвідношення 4:5, щоб в маленькій і великій картках завиток не плавав.
- **Оновлення:** service worker із новою версією кешу видаляє попередні кеші.

## Що було додано у v2

1. **Головна сторінка:** компактна спіраль, коротший опис і дві великі кнопки вище. Висота фіксована до мобільного viewport — головна не прокручується; враховані `safe-area-inset` iPhone.
2. **Ідеї:** 5 розділів × 5 фото (25 прикладів): тварини, портрети, їжа, природа, архітектура. У кожного фото є коротка порада; поверх нього через Canvas малюється золота спіраль. Горизонтальне гортання та збільшення фото натисканням.
3. **Камера:** прибрано постійний текст-підказку під прев’ю; режим називається **«Датчик»**; ліхтарик і повернення поміняні місцями; фотоекран майже до країв телефона.
4. **Галерея → камера:** після закриття галереї потік повторно підключається до відеоелемента для подолання типового збою відображення на iOS Safari. Якщо потік завершився, камера запускається заново.
5. **Датчик:** відносні повороти обробляються кватерніонами, проєкція цілі враховує перспективу, застосовано приглушення дрібних коливань і пропуски дуже дрібних рухів. Це точніше за незалежне додавання `alpha`, `beta`, `gamma`, але **все ще не computer vision / SLAM**.
6. **PWA:** кеш оновлено до `spiralcam-app-v3`, щоб користувачам прийшла актуальна версія.

## Камера та фото

- Передня/задня камера, LED там, де підтримується, формати 4:5 / 1:1 / 3:4 / 9:16 / 16:9.
- Золота логарифмічна спіраль (плавне наближення спіралі Фібоначчі): поворот, дзеркало, масштаб, сітка, товщина та колір.
- Один знімок створює **два файли JPEG**: із золотою спіраллю та без неї. Пояснення, мітки й елементи керування на фото **не потрапляють**.
- У віртуальній галереї можна завантажити один JPEG, обидва одним ZIP або видалити обидві версії. Фото зберігаються в IndexedDB браузера.
- У «Датчику» спочатку дозвольте сенсори руху, потім торкніться об’єкта у кадрі. Обертайте телефон **на місці**, не переміщаючи його горизонтально: мітка має наблизитися до завитка. Коли відстань мала, спіраль стане зеленою.

## Фотоідеї та джерела

**25 прикладів** зберігаються як список у `app.js` (масив `PHOTO_IDEAS`).

- **Тварини (5)** — авторські AI-зображення у папці `examples/`. Вони працюють без зовнішнього інтернету після встановлення сайту.
- **Портрети, їжа, природа, архітектура (20)** — зображення Unsplash, які завантажуються через `https://images.unsplash.com/`. Вони потребують доступу до інтернету; за відсутності мережі картка покаже позначку «Фото доступне онлайн». Використовуються за [Unsplash License](https://unsplash.com/license). За бажання їх можна завантажити в `examples/` і замінити шляхи у `PHOTO_IDEAS` для повної офлайн-роботи.

Фотографії у гіді є **ілюстрацією можливої композиції**, а не твердженням, що всі предмети або природні структури математично мають золоті пропорції.

## Публікація на GitHub Pages

1. Створіть репозиторій на https://github.com/new, наприклад `spiracam`.
2. **Розпакуйте ZIP і завантажте у корінь репозиторію всі файли, зберігши директорії `icons/` і `examples/`.** Файли `index.html`, `app.js`, `styles.css`, `service-worker.js` мають бути у корені.
3. Відкрийте **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
4. Перейдіть на `https://ВАШ-ЛОГІН.github.io/spiracam/` через Safari або Chrome та дозволіть доступ до камери.
5. Якщо на iPhone відображається стара версія, перезавантажте сторінку або закрийте та відкрийте встановлений PWA; у складному випадку очистіть дані цього сайту (**це видалить локальні фото!**).

## Обмеження

- Датчики повідомляють про **поворот телефона**, не відстежують сам предмет у зображенні. Без комп’ютерного зору не можна обіцяти абсолютної стабільності позначки при зміщенні телефона, зміні фокуса чи сильних електромагнітних завадах.
- На iOS доступ до DeviceOrientation може вимагати окремого дозволу після натискання кнопки. Не всі браузери повертають стабільні показання.
- LED — підтримуване браузером безперервне світло, не системний імпульсний спалах. У багатьох iPhone браузер не дозволяє його вмикати.
- Якщо очистити дані сайту або відкрити його в приватному режимі, віртуальна галерея може зникнути. Завантажуйте важливі фото на телефон.
- На GitHub Pages потрібен HTTPS (видається автоматично). Відкриття `index.html` з файлового менеджера телефона не є повноцінним тестом камери.

## Тестування

В режимі тестового потоку перевірено: 402×874, 390×844, 375×667 та 320×568; 25 карток ідей; попередній перегляд; збереження пари JPEG; видалення з галереї; переприв'язку живого відеопотоку й повторне фото. **Фізичні сенсори та апаратний LED iPhone 16 Pro не перевірялися.**
